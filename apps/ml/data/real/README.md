# Real observation datasets

This directory is the canonical location for **real-world** observation
CSVs that feed `tideguard_ml.eval.real_validation`. Synthetic test data
lives in-process inside `SyntheticDataset` and is not stored here.

Files are `.gitignore`d by `data/raw/` and friends, so contributors must
either commit the curated, license-cleared CSV explicitly or store the
raw downloads outside this directory.

## Expected schema (`black_sea_template.csv`)

| Column | Required | Units | Notes |
|--------|---------:|-------|-------|
| `lon` | yes | degrees east | WGS-84 |
| `lat` | yes | degrees north | WGS-84 |
| `ts_seconds` | yes | UNIX seconds (UTC) | observation time |
| `concentration` | yes | items / m² (or kg / km², be consistent within one file) | non-negative |
| `source` | recommended | free text | citation key — e.g. `Pogojeva2021_S1`, `MDMAP_2022_BG` |
| `license` | recommended | free text | SPDX-compatible identifier — e.g. `CC-BY-4.0` |
| `debris_type` | optional | free text | `macro`, `meso`, `micro`, `nano` |
| `notes` | optional | free text | provenance reminder |

## Curated sources (target list)

| Source | Status | License | Coverage |
|--------|--------|---------|----------|
| **Pogojeva et al. 2021** — Supplementary S1 | manually digitise the supplementary CSV | CC-BY-4.0 | Russian Black Sea, 2018–2020, ~200 points |
| **NOAA Marine Debris Tracker** | API: `https://debristracker.org/api/` | CC-BY-4.0 | global, Black Sea sparse |
| **NOAA MDMAP** | CSV export from `marinedebris.noaa.gov` | CC-BY-4.0 | global, mostly NA + EU |
| **EMODnet Chemistry — Marine Litter** | WMS / WFS at `https://emodnet.ec.europa.eu/` | CC-BY-4.0 | Bulgarian / Romanian Danube plume |
| **OSPAR Beach Litter** | `https://odims.ospar.org/` | CC-BY-4.0 | NE Atlantic (use as Mediterranean expansion proxy only) |

Litterati and proprietary city-level datasets are intentionally **not**
on this list — see `docs/DATA_ETHICS.md`.

## Reproducing the bundled template

`black_sea_template.csv` ships **10 illustrative rows** so the unit test
suite + the `real_validation` CLI have something to chew on offline. Do
not use it for any published claim — it is a *schema example*, not a
dataset.

The full reproducible bundle (~200 rows) is generated by
`scripts/build_black_sea_observations.py` (offline-safe fallback to the
template when CMEMS / Pogojeva downloads fail).
